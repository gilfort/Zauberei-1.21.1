# Witchwood School

When `spawn_witchwood_school` is enabled, the school template (`zauberei:witchwood_school`) is placed once when a
**new** world is created, high above the world spawn (corner at `-16 244 -23`, roughly centered on x/z 0).
Existing worlds are not changed.

The option is off by default (see [Configuration](Configuration)). The template can be replaced with a datapack
at `data/zauberei/structure/witchwood_school.nbt`.
